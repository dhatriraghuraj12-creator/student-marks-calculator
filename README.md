# Student Marks Calculator

A beginner-friendly mini project built with HTML, CSS, and JavaScript. Enter a student's name and marks in five subjects to calculate total marks, percentage, grade, and pass/fail status.

## Features

- Accepts a student's name and marks for five subjects
- Calculates total marks out of 500
- Calculates percentage
- Displays a grade
- Checks pass/fail status (35 marks required in every subject)
- Validates empty and out-of-range inputs
- Responsive layout for desktop and mobile screens
- Reset button to clear the form

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enter the student's name and a whole-number mark from 0 to 100 for each subject.
4. Click **Calculate result**.

No installation or external libraries are required.

## Sample Grading Rules

| Percentage | Grade |
| --- | --- |
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 35–59.99% | D |
| Below 35% | F |

A student must score at least 35 in every subject to pass. These rules are examples and can be changed to match your institution's grading policy.
